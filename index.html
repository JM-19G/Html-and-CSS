If you just want to see your website in the browser The easiest option is Live Server in VS Code. Open index.html in VS Code. Right-click inside the index.html file. Select Open with Live Server. Your browser should open automatically. You'll see an address similar to: http://127.0.0.1:5500/ If "Open with Live Server" isn't available Install the Live Server extension in VS Code: Click the Extensions icon on the left (Ctrl + Shift + X) Search Live Server Install it Go back to index.html Right-click → Open with Live Server Important You don't need npm for this project.
